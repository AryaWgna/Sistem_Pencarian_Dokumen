# E-Arsip - Smart Document Search System
*For Indonesian version, see below / Untuk versi bahasa Indonesia, lihat di bawah.*

A digital document archiving and retrieval system powered by Machine Learning. This web application utilizes **TF-IDF** for relevance ranking and **Multinomial Naïve Bayes** for automated document classification.

## Features
- **Document Management**: Centralized digital storage for administrative documents, letters, and reports.
- **Smart Search Engine**: Uses TF-IDF (Term Frequency-Inverse Document Frequency) combined with Cosine Similarity to rank search results based on contextual relevance rather than exact keyword matching.
- **Auto-Categorization**: Employs a Multinomial Naïve Bayes classifier to automatically predict and assign document categories upon upload.
- **Data Preprocessing**: Integrated NLP pipeline for Indonesian language including case folding, tokenizing, stopword removal, and stemming (via Sastrawi).
- **Evaluation Dashboard**: Built-in metrics to evaluate classification model performance (Accuracy and Confusion Matrix).

## Tech Stack
- **Backend Framework**: Python / Flask
- **Database**: SQLite (via SQLAlchemy ORM)
- **Machine Learning**: scikit-learn
- **NLP**: Sastrawi (Indonesian Stemmer)
- **Frontend**: HTML5, CSS3, Bootstrap 5

## Architecture & NLP Pipeline
1. **Text Preprocessing**: Uploaded documents are parsed and cleaned (stopword removal, stemming).
2. **Vectorization**: The system builds a TF-IDF matrix to represent document features mathematically.
3. **Classification**: The Naïve Bayes model calculates prior and posterior probabilities from the TF-IDF vectors to predict document categories.
4. **Retrieval**: When a search query is executed, it is vectorized and compared against the document corpus using Cosine Similarity to return ranked results.

## Installation & Setup

### Prerequisites
- Python 3.8+
- pip (Python package manager)

### 1. Clone & Setup Environment
```bash
git clone https://github.com/AryaWgna/Sistem_Pencarian_Dokumen.git
cd Sistem_Pencarian_Dokumen

# Create and activate virtual environment
python -m venv venv
# Windows: venv\Scripts\activate
# Linux/Mac: source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### 2. Initialize Machine Learning Models
Before running the application, the AI models (`.pkl` files) must be generated by training on initial data.
```bash
python scripts/training_awal.py
```

### 3. Run the Application
```bash
python run.py
```
The application will be accessible at `http://127.0.0.1:5000`.

# E-Arsip - Sistem Pencarian Dokumen Cerdas (Versi Indonesia)

Sistem pengarsipan dan pencarian dokumen digital yang ditenagai oleh Machine Learning. Aplikasi web ini memanfaatkan **TF-IDF** untuk penentuan peringkat relevansi dan **Multinomial Naïve Bayes** untuk klasifikasi dokumen secara otomatis.

## Fitur Utama
- **Manajemen Dokumen**: Penyimpanan digital terpusat untuk dokumen administratif, surat, dan laporan.
- **Mesin Pencari Cerdas**: Menggunakan TF-IDF digabungkan dengan Cosine Similarity untuk mengurutkan hasil pencarian berdasarkan relevansi kontekstual, bukan sekadar pencocokan kata kunci eksak.
- **Kategorisasi Otomatis**: Memanfaatkan model klasifikasi Multinomial Naïve Bayes untuk memprediksi dan menetapkan kategori dokumen secara otomatis saat dokumen diunggah.
- **Pra-pemrosesan Data**: Pipeline NLP terintegrasi untuk bahasa Indonesia, meliputi *case folding*, *tokenizing*, penghapusan *stopword*, dan *stemming* (menggunakan Sastrawi).
- **Dasbor Evaluasi**: Metrik bawaan untuk mengevaluasi kinerja model klasifikasi (Akurasi dan Confusion Matrix).

## Stack Teknologi
- **Backend Framework**: Python / Flask
- **Database**: SQLite (via SQLAlchemy ORM)
- **Machine Learning**: scikit-learn
- **NLP**: Sastrawi (Indonesian Stemmer)
- **Frontend**: HTML5, CSS3, Bootstrap 5

## Arsitektur & Pipeline NLP
1. **Pra-pemrosesan Teks (Preprocessing)**: Dokumen yang diunggah diproses dan dibersihkan (penghapusan stopword, stemming).
2. **Vektorisasi**: Sistem membangun matriks TF-IDF untuk merepresentasikan fitur dokumen secara matematis.
3. **Klasifikasi**: Model Naïve Bayes menghitung probabilitas *prior* dan *posterior* dari vektor TF-IDF untuk memprediksi kategori dokumen.
4. **Pencarian (Retrieval)**: Saat kueri pencarian dijalankan, kueri divoktorisasi dan dibandingkan dengan korpus dokumen menggunakan Cosine Similarity untuk mengembalikan hasil yang diurutkan.
